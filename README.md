# PoseFill AI update check

The PoseFill AI Blender add-on reads the latest release of this repository once a day to tell its
users when a newer version is out. The add-on itself is sold on Superhive:
https://superhivemarket.com/products/posefill-ai

To announce a version: publish a release whose tag is the version number (`0.1.1` or `v0.1.1`) and
write the change list in the release notes. The add-on shows the notes and links to the store page.
